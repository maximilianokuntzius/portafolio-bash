# ⚙️ Portafolio de Automatización y Operaciones de Datos (Bash)

Este repositorio contiene una colección de scripts en Bash diseñados para optimizar flujos de trabajo operativos, automatizar tareas repetitivas y preparar datos estructurados para su posterior análisis (ej. mediante SQL).

## 🎯 Objetivo del Proyecto
Demostrar la capacidad de utilizar la terminal de Linux para resolver problemas de gestión diaria, limpiando registros masivos (como logs de transacciones o reportes CSV) y garantizando la eficiencia en los procesos del sistema.

## 📂 Estructura del Repositorio

*   **/procesamiento-datos:** Scripts diseñados para filtrar, limpiar y organizar información cruda proveniente de reportes diarios.
*   **/utilidades-sistema:** Herramientas para la gestión rápida de permisos, carpetas y automatización de respaldos.
*   **/herramientas-git:** Scripts de automatización de control de versiones.

### 📜 Catálogo de Scripts Actuales

| Archivo | Descripción | Impacto Operativo |
| :--- | :--- | :--- |
| `subir.sh` | Automatiza el proceso de empaquetado y control de versiones (Git). | Reduce el tiempo de despliegue a un solo comando. |

## 🚀 Cómo ejecutar estos scripts

Para probar cualquiera de estas herramientas en un entorno Linux/macOS:
1. Clona este repositorio: `git clone https://github.com/maximilianokuntzius/portafolio-bash.git`
2. Ingresa a la carpeta: `cd portafolio-bash`
3. Otorga permisos de ejecución al script deseado: `chmod +x nombre_del_script.sh`
4. Ejecútalo: `./nombre_del_script.sh`
